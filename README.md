  # VISADA

  **Verificação Integrada de Sinal, Alcance, Desdobramento e Antenas**

  Planejamento de enlaces e cobertura de rádio sobre o terreno, de HF a SHF.

  **[Site e demonstrações](https://lpluiz.github.io/visada-app/)** · **[Baixar para Windows](../../releases/latest)**
</div>

---

Este repositório guarda o **site** do VISADA e o **programa para Windows** (na aba Releases). O código-fonte do programa não é público.

- **Site:** `index.html`, `estilo.css`, `site.js`, imagens em `img/` e `demo/`.
- **Demonstrações:** `demo/` tem telas e documentos gerados pelo próprio VISADA com um projeto de demonstração (`dados/projeto-demonstracao.json`), que também abre no programa (aba Planejamento rádio, etapa 1, Abrir arquivo).
